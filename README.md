A newspaper front page drawn in a single image that sums up Tuesday 17 November 2026: the Kerch Bridge arch collapsing after Ukraine's second strike in a day and Russia's retaliatory hits on Kyiv's bridges, Iran's drone attack on a US radar in Bahrain amid tanker strikes in the Strait of Hormuz, the confirmed first Xi–Trump–Putin summit in Shenzhen, the Optimizely supply-chain hack that slipped malware into 178 major websites, the Pentagon's ninth straight failed audit, and ULA's Tuesday update on the Vulcan launch failure that lost 40 Amazon Leo satellites. Each story gets a flat illustration, a headline and one short summary line, under a masthead naming the day. The image is pre-rendered with Pillow (`dev/render.py`); `main.py` (standard library only) copies it to the output directory, so every run writes identical bytes.
